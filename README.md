# AejisCore（イージス・コア）

**ワイヤーアクションと武器で拠点を守る、近未来防衛アクションゲーム**です。  
マウスホイールで武器を切り替えながら、空中を駆け、迫り来る敵からコアを守ります。  

## ゲーム概要
- プレイヤーは**ワイヤーアクション**でフィールドを高速移動
- **マウスホイールで武器切り替え**、状況に応じた戦い方が可能
- 防衛の要となる**タレットの強化・配置**が攻略のカギ
- 防衛施設を舞台に、連続で襲ってくる敵を殲滅

## 制作情報
- **開発者：Allow-hub（個人制作）**
- **制作期間：1か月**

## 工夫・良かった点
- **VoiceVoxを活用し、キャラクターに音声を実装**  
  → ゲーム中の没入感や演出力を向上
- **ワイヤーアクションにトレイルを付加し、演出面を強化**  
  → 高速移動時に視覚的な気持ちよさを演出

## 反省点・今後の改善点
- ワイヤーアクションの**操作性に難があり、プレイヤーの意図とズレることがあった**  
  → より直感的に動けるよう、補正やエイムアシスト等の導入も視野に入れている
